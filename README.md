# Submarine Commander (潜水艦アクションゲーム)

Node.js (Express) と HTML5 Canvas で作られた、ブラウザで遊べるシンプルな2D潜水艦アクションゲームです。
<img width="1454" height="1066" alt="スクリーンショット 2026-05-28 144310" src="https://github.com/user-attachments/assets/9f2e10ea-ba2e-41ea-a53b-5817575102a5" />

## ✨ 特徴
- 潜水艦特有の「慣性が働く独特の操作感」
- 敵（駆逐艦）に向かって追尾する「誘導魚雷システム」
- 潜水艦が真下を通ると落とされる恐怖の「爆雷攻撃」
- EASY / NORMAL / HARD から選べる「難易度設定機能」

## 🚀 起動方法
1. リポジトリをクローンまたはダウンロード
2. `npm install` で依存関係をインストール
3. `node server.js` でサーバーを起動
4. ブラウザで `http://localhost:3000` にアクセス
